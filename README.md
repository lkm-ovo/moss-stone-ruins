# 苔石遗迹 · Moss Stone Ruins

中文俯视角动作冒险。选择种族，进入随机遗迹，探索房间、收集装备与遗物，逐层挑战首领。

- **[网页试玩](https://lkm-ovo.github.io/moss-stone-ruins/)**：在支持 WebGL 2 的电脑浏览器打开，点击「开始试玩」。需要键盘和鼠标，首次加载约 270 MB。请允许网站存储，进度才能留在当前浏览器。
- **[下载 Windows 试玩版](https://github.com/lkm-ovo/moss-stone-ruins/releases/tag/v1.0.0-preview.1)**：下载 `MossStoneRuins-Windows-x64.zip`，完整解压后打开 `MossStoneRuins.exe`。请将 EXE 和 PCK 留在同一个文件夹。无需安装 Godot；此试玩包未做代码签名。

选角页右上角可以启用「轻量画面」，简化迷雾的流动和纹理。Windows 和网页版的进度分别保存在本机。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD 或按住鼠标中键 |
| 普攻与种族能力 | 左键与右键 |
| 闪避、互动 | 空格、F |
| 地图、装备 | M、Tab |
| 保存、暂停 | F5、Esc |

长弓可边走边蓄力，按住左键可连续出箭。当前试玩版已在 Windows x64 和 Edge 验证，手机触屏尚未适配。

第三方引擎与素材许可随试玩包提供。
